# 新电脑准备与本人登录

## 首次对话

先问一个问题：“你负责哪些垂类？”随后按需逐项确认排除范围和专项例外；不要一次要求用户提供大量技术信息。若本次已明确范围，不必重复询问。

Codex 自己检查工具和项目，不让用户寻找 Token、Cookie、AK 或配置文件。首次设置不等于授权保存策略；配置仍须单独确认。

## 选择可用执行路径

1. 已有 `level_config_rpa`：复用项目、接口和标准登录流程，走脚本路径。
2. 没有项目，但 Codex 内置浏览器可用：使用内置浏览器完成后台登录、只读检查和已确认的页面配置。明确这是浏览器路径，不声称接口脚本已就绪。不接管日常 Chrome。
3. 必须使用接口但缺少项目：报告缺少后台适配器，请用户提供可信项目目录或组织认可的安装来源。公用 Skill 未分发该内部项目；不要猜仓库、下载第三方项目、复制其他电脑的 profile 或临时重写认证。

普通浏览器能登录，不等于脚本或 CLI 登录态有效。不得把两种会话混为一谈。

## 脚本环境准备

依赖：Node.js 22+、npm、已有后台项目及其 `src/browser_api.js`、`src/constants.js`、`package.json`。自动安装入口支持 macOS/Linux；Windows 需先按可信项目说明准备依赖，再做只读检查。本 Skill 不包含后台项目、账号和浏览器 profile。

通过当前进程环境变量指定用户自己的项目，勿写入公用仓库：

```bash
export STRATEGY_CONFIG_RPA_ROOT="/absolute/path/to/level_config_rpa"
node scripts/setup-environment.mjs
```

该命令只检查依赖，不打开浏览器、不安装软件、不访问后台。确认使用可信项目后，缺少依赖时执行：

```bash
node scripts/setup-environment.mjs --install-deps
```

安装仅在用户提供的项目中执行 `npm ci --ignore-scripts`（有 lockfile）或 `npm install --ignore-scripts`（无 lockfile），再调用该项目已安装的 Playwright 安装 Chromium。不修改全局 npm、不运行项目 lifecycle 脚本、不下载后台项目。若被禁用的安装脚本导致其他依赖不可用，报告并单独处理，不自动解除限制。

## 登录与续期

默认先在后台验证已有会话：

```bash
node scripts/check-session.mjs
```

失败后停止，不自动跳到日常 Chrome。只有用户明确允许打开登录窗口时运行：

```bash
node scripts/check-session.mjs --login
```

此命令显式打开独立 Playwright Chromium，绑定用户项目下 `.browser-profile`，等待本人通过正常 SSO/扫码等完成登录，最长 5 分钟；用户的密码、验证码和 MFA 由本人填写。该窗口不是 Codex 内置标签，应提前说明。若用户只允许内置浏览器，则走内置浏览器路径，不假称其登录会同步到脚本。

会话由浏览器按正常机制保存在用户自己的本地 profile 中；不要导出、读取、打印或上传凭据，不将 profile 打包到 Skill。共享电脑需使用个人系统账号；不复用别人的 profile。更换账号先停止任务，由用户通过正常退出/登录流程操作，不删除 profile、不自动继承旧账号。

`check-session` 只复用 `ensureLogin` 并读取垂类列表和一个处理等级详情。页面能打开但接口不可读仍判为失败；返回空列表或无详情也不算验证通过。仅输出验证状态及读取数量，不输出页面正文、接口响应、凭证或敏感 URL 参数。

成功后关闭窗口，再运行一次无 `--login` 的检查，验证后续无头脚本能复用登录。登录成功不代表策略已保存。脚本就绪后仍要按需求读取最新配置、输出确认稿，用户确认后才写入。

登录过期、profile 被占用、网络/权限失败时停止，不杀浏览器、不强删锁、不无限重试。不要自动发起权限审批或切换账号。底层接口模块应是可信且已核实的；本入口不调用 AK 换取逻辑、不读取 AK 文件、不新建认证链路。

## 内置浏览器路径

后台打开/绑定兼职平台分发系统标签，先只读判断登录态。需要登录时向用户说明并在用户允许后展示已有标签，由本人登录。登录后重新绑定并核验页面、垂类列表及目标详情；只在该会话中继续，不复制 Cookie 给其他浏览器。遇到控制句柄失效按内置浏览器恢复流程重新绑定，不把它误报为退出登录。

## 就绪报告

分别报告：负责范围是否确认、执行路径、项目依赖状态、本人登录是否完成、后台列表/详情是否可读、尚未验证项。无法安全获取当前账号名称时，请用户核对页面账号，不凭列表内容推断身份。只有这些准备完成后才进入策略配置确认流程。
