# 飞书登记

## 读取和写入

电子表格始终使用用户身份：

```bash
lark-cli --as user sheets ...
```

写入前读取 workbook 信息、sheet 列表、表头和目标行。不能按旧行号、旧 sheet 名或截图位置猜测。

## 截图登记流程

1. 从当次需求读取目标文档 URL、sheet ID、登记列和垂类定位字段。
2. 读取表头并按垂类、任务池、专项名称定位行。
3. 配置完成后截图，截图至少包含垂类、处理等级、优先级名称和关键筛选条件。
4. 写入指定登记位置，不能写到相邻专项或旧 sheet。
5. 读回目标单元格，确认状态和图片/附件确实存在。

## 常见登记位置

- 新品在售：`在售项目-关联组-已录入未关联属性明细`。
- 渠道在线率/专项收口：需求指定的“策略组需求-线上配置情况-新建收口汇总”对应 sheet。
- 商品全周清：`商品全标签内部下发记录`。

如果需求同时给出多个相似文档或 sheet，必须在写前确认本次使用的具体 sheet，不能默认沿用历史登记位置。
