# 来源汇总与数据完整性

## 本期数据契约

先列清每份文档的标题、wiki/工作簿、每个来源sheet的ID和名称、角色、真实表头行、读取列及本次权威等级列。五sheet是常见结构，不是固定数量；只汇总用户本次确认的来源，不额外把已有汇总、配置用表、确认版汇总再叠加一次。

常见来源是低效网格、上期无策略网格、剩余网格以及两档站外黑名单命中明细。`业务调整等级`是权威；如用户指定某次新增后缀列，必须精确记录并检查列存在。建议等级、关联输出等级和业务等级不能混用。

必需身份：垂类、网格ID、sheet归属/来源行。网格名称用于核对和输出，不凭名称补ID。等级允许读取为空，但正式配置前必须处理异常。结论空不阻断，方向空默认提醒，用户已明确无需方向时可省略此提醒。

## 完整读取

1. `+workbook-info`枚举指定文档全部sheet和revision；读取表头，核对真实字段。
2. 按sheet真实物理范围分批读取。明确 `--skip-hidden=false`；禁止只抓可见页面/筛选结果，禁止以屏幕最后一行当真实末行。
3. 网格ID读取使用 `+cells-get --include value` 的原始值，核对 `row_indices`、`col_indices`、`actual_range`、`has_more`、`truncated` 与 `complete`。某些typed读取会将日期形网格变成序号，不用它生成主键。
4. 保留物理行号、来源URL、sheet名及读取时点。业务数据缺行不填空对象假装完成。
5. 分页须核对页数、总行数、主键唯一性和首中末。读取前后比较revision；有变化则重读受影响文档，不能把不同时点合成“最新”。自己的汇总写入也会改变文档revision，应改为回读全部来源字段确认未变。

常用CLI形式按当前 `lark-sheets` reference核实；不盲用旧版本参数。输出路径使用当前目录相对路径，数据大时写本地临时证据，不输出整表到聊天。

## 归并与异常

以`垂类+网格ID`为键。同级重复可归并并保留全部来源及行号；跨来源不同等级一律冲突，包含“不清理”和任何1至4的冲突。任一来源等级空也保留异常，即使另一来源非空；不能自行用另一份覆盖。

等级只接受`处理等级1`至`处理等级4`和`不清理处理等级`。特殊别名或“1”等编码只有当前源契约明确允许时才映射；后台名称别名与飞书业务等级是两件事。

日期标签如`12月14日`只有用户明确允许修复日期型网格时才还原`12-14`，记录原值和来源。数值`46370`不通过猜日期修复。所有修复核对后台网格有效性。

输出至少包含：垂类、网格id、业务网格评估反馈结论、业务调整等级、方向、sheet归属、网格id-配置用（ID后一个英文逗号）。建议加网格名称、来源行、核验状态和备注。异常表按网格分组，展示每个冲突sheet的真实等级，而非只写“冲突”。

## 写入汇总

只写用户指定或新建的目标汇总，不覆盖业务源列及其他人的sheet。目标存在时优先按键比较、更新变化行；数量/排序改变时先明确尾部旧行如何处理，不能留残留记录。保留本轮旧目标快照。

保持相邻格式、冻结表头、编号文本格式；不用空字符串表示空白。typed `table-put` 的`null`实测可能保留旧单元格，不能据此宣称清空；逐格回读。已补齐异常可将旧说明改成“业务调整等级已补齐，复核通过”，并撤除旧标红；真清空按飞书skill及本次授权执行，不绕确认门禁。

同一 `table-put` payload不重复填同名sheet来模拟离散写入；拆独立区域或用当前CLI的离散写工具。样式单次完整包围区域有格数上限，大表每批独立调用，不同次拆列仍可能被合并超限。颜色回读统一大小写比较。

写后全量回读目标，与独立来源逐键比较；核对来源覆盖、去重、各垂类各等级数量及集合、真正空白、当前异常备注/背景色和非目标内容。汇总“最新”仅指本次成功读取时点，不承诺文档之后不会被业务更新。
