# 真实截图与飞书登记

用户给出登记文档后，先读取当前sheet、关联组板块表头和其他垂类同列的样例。B至F是历史常用列，不能固定认为列号含义不变；按本次表头定位“是否配置完成、配置人、配置时间、等级1至4截图、黑名单截图”。没有要求的列不写。

## 截图

- 等级图必须进入兼职平台本次**网格分配页**，展示正确垂类、任务池、四档和网格总数。不能截策略优先级条件页、飞书汇总或自绘表格。
- 若样例通过“批量删除”模式显示数量，可打开该模式、勾选本次目标并截图，随后取消/关闭。**绝不点击确认删除**。截图登记任务没有删除配置授权。
- 黑名单图按同列样例取真实列表/详情，露出目标垂类、数量和状态。需要框选则仅对真图增加红框；保留原图与框坐标，不能改字、改数、重绘页面或生成看起来像截图的图片。
- 每张图片保存后先自己查看，确认清晰、目标框正确、数量未遮挡、没有凭据和无关个人信息。不满足则重截，不把上传成功当截图正确。
- 写入单元格图片或样例所用图片方式；读回图片token/引用，再查看登记表里的实际显示，保证没有传错垂类或沿用旧图。

## 状态、姓名和日期

“已配置”只能用于本期验收通过的范围；审批/同步未完成按实际状态说明，不能用截图填表让未完成变完成。配置人使用本次指定姓名/“填我”对应当前本人，无法确认时问一次，不能从历史文档猜。

日期取**本次实际配置日期**或用户明确指定日期；今天只是登记旧配置时，不擅自把日期改今天。跨月任务不复用旧日期，年/月/日明确，保持相邻格式。图书等本次排除垂类不填。
