# 兼职平台策略与网格配置 Skill

当前版本：**v1.2.0**。一个入口自动识别策略条件、混排、网格汇总、等级分配、黑名单及截图登记任务。具体范围和安全规则见 [SKILL.md](SKILL.md)，变更见 [CHANGELOG.md](CHANGELOG.md)。

## 安装或更新

在 Codex 中发送：

```text
请安装或更新 https://github.com/wenbofan0515-afk/strategy-condition-config 的仓库根目录 Skill，名称为 strategy-condition-config，使用最新已发布版本。先检查本机安装位置和版本；如已安装则先备份，保留个人配置和登录态，在临时目录校验新版后再替换，失败时恢复。若存在独立的 grid-distribution-config，先备份并保留其中的个人文件，再移出 Skill 目录，避免重复；不要上传备份或凭据。完成后报告版本和来源提交，不操作线上后台，并说明是否需要新开会话。
```

安装后建议新开会话，使用 `$strategy-condition-config` 或直接描述任务。安装不代表已具备后台权限和项目依赖。

每个会话首次使用时检查新版本，仅提醒，不自动升级。网络或来源异常时显示未知。策略 v1.1.1 可检查统一版本；更早版需先手动更新。旧独立网格版只检查 `grid-v*` 标签，不会自动发现统一版本，需按上述提示词手动迁移。旧标签保留以供追溯。

不得将个人范围、业务快照或凭据放入发布包。后台真实写入仍需按照具体需求和授权执行，离线测试不等同业务验收。
